Detailed Description

BaseThread that polls valve + driver-IC + ADC diagnostics.

Every iteration (default 100 ms = 10 Hz):

  1. Walks every valve and calls OnDiagnostics() so each MAX22200 / TLE92466ED per-channel fault flag is decoded and the per-valve diagnostic snapshot is refreshed.
  2. Reads the device-level (global) fault registers from both driver ICs and aggregates them into SubsystemFaultSnapshot. This is the single source of truth the application can poll for "is anything bad happening at the chip level?":
    • MAX22200: OVT (die over-temperature), COMER (SPI comm error), UVM (under-voltage), per-fault masks.
    • TLE92466ED: VBAT/VIO/VDD UV/OV, central OT error/warning, clock fault, SPI watchdog, ECC errors, mission-mode flag.
  3. Tracks ADS7952 handler readiness — alarm-bit scrape is left as a TODO until the ADS7952 driver exposes an alarm-readback helper.

The thread never blocks the high-rate control thread because all valve state writes are done atomically through the same RecordFault() path that solenoid/proportional valves use during Apply().

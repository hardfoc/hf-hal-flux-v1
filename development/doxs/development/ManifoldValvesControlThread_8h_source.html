104 // 16 kB stack: the first Apply() on each ProportionalValve enters
105 // Configuration Mode, writes a ChannelConfig (held by value on the
106 // stack), pushes PWM + dither (each of which allocates its own
107 // step/freq/clk-div lookup tables on the stack inside the TLE92466ED
108 // driver), then re-enters Mission Mode. With the default 6 kB the
109 // task overflows the moment that round-trip starts. 16 kB gives
110 // ample headroom for the driver's lambdas, mutex locks and inline
111 // ESP_LOG calls without affecting RAM budget meaningfully.

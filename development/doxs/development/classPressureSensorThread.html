Parameters
sample_interval_msWorker step period (ms). 1 ms (= 1 kHz) matches the SSC sensor's internal ASIC rate.
avg_samplesADC averaging used only by Sample() during calibration (live path uses Auto-1 batch + software IIR via PressureSensor::Update).
filter_cutoff_hzIIR low-pass cutoff applied per channel. 0 disables filtering. Default 100 Hz at 1 kHz sampling gives ~1.6 ms group delay — comfortable for control loops up to a few hundred Hz.

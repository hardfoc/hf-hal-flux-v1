◆ kNormalizeBus

constexpr bool cfg::kNormalizeBus = true
constexpr

When true the example runs a multi-baud discovery sweep at start-up and then NormalizeBusBaud() so every device ends up at kNormalizedBaud before the steady-state loop starts.

Set to false to skip the sweep entirely (saves ~3 s on boot when you already know everyone is at the factory baud).

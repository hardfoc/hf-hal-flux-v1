HardFOC Flux HAL — ESP32 Examples

Overview

This directory contains buildable ESP-IDF examples that exercise the Flux HAL API from lib/api/Flux.h. Each .cpp file in main/ is a standalone test/example that can be built and flashed independently using the build_app.sh script.

Full catalog of every APP_TYPE, CI flags, and paths: docs/README.md (kept in sync with app_config.yml).

Available Examples (short list)

App Type Source File Description
flux_api_test flux_api_test.cpp Full Flux API initialization and diagnostics
flux_nvs_example flux_nvs_example.cpp NVS / NvsManager — flux / flux_cal / flux_cfg, boot counter, blob, string

./scripts/build_app.sh list

Build System

This project uses the same build infrastructure as the HardFOC external driver examples. The scripts/ directory is a Git submodule pointing to the shared build tooling repository.

Each example is built by passing APP_TYPE and BUILD_TYPE to CMake via build_app.sh, which maps the app type to the correct source file.

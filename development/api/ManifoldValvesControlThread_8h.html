Detailed Description

BaseThread that pushes pending valve setpoints to the driver ICs.

Runs on its own RTOS task at a fixed period (default 10 ms / 100 Hz). Each iteration walks every valve in the ManifoldValves; for any valve whose dirty flag is set, it calls Apply() so the new setpoint reaches the hardware.

The thread is intentionally lean: it does NOT poll fault registers, it does NOT read back diagnostics — that is the dedicated diagnostics thread's job. This separation makes it cheap to call RequestPosition from a 500 Hz control loop without ever stalling on SPI register reads.

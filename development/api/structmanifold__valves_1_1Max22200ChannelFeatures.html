Detailed Description

Which MAX22200 per-channel diagnostic features should be enabled.

These map onto the MAX22200's per-channel CFG_CH register bits:

  • SRC — Slew Rate Control (reduces EMI, only valid when fCHOP < 50 kHz)
  • OL_EN — Open-Load detection
  • DPM_EN — Detection of Plunger Movement (low-side only). When the plunger doesn't move under load, MAX22200 raises a DPM fault — a critical safety signal in medical applications because it indicates a stuck or absent valve mechanism.
  • HHF_EN — HIT current check (HHF fault if IHIT not reached in tHIT; only meaningful for BinaryHitHold)

Defaults are chosen for medical-device behaviour: open-load detection is always on, slew-rate control is on (cleaner edges), HHF check is on for hit-and-hold solenoids, and DPM is on for binary solenoids with a known mechanical signature.

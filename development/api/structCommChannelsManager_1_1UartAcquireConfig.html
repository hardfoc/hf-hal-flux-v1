Detailed Description

Lazy-acquire configuration for an ESP32 UART port.

Apps that own a serial sensor (BASIS-2, FDO2, …) supply this to AcquireUart(). The HAL owns the port; the app owns the device driver layered on top of the returned BaseUart&.

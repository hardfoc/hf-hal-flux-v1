Detailed Description

GPIO management for the HardFOC Flux V1 platform.

The Flux board uses only ESP32 internal GPIOs (no GPIO expander). Control pins for MAX22200 and TLE92466ED are managed as standard GPIOs. This is simpler than the Vortex GpioManager which spans 3 chip types.

Design improvement over Vortex: uses a fixed-size array for GPIO storage (all pins known at compile time) instead of heap-allocated unordered_map. String lookups go through a constexpr mapping table.

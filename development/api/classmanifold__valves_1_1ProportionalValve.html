 Request a normalised position 0..1. @Browser For binary solenoids this is interpreted as 0 → off, > 0 → on. For variable-current solenoids and proportionals it linearly maps to current 0..full_flow_ma. The control thread observes the change on the next iteration and pushes it to the hardware. Out-of-range values are clamped.

◆ Apply()

hf_valve_err_t manifold_valves::ProportionalValve::Apply ( )
inlineoverridevirtualnoexcept

Apply the current setpoint to the underlying driver IC.

Returns
The hf_valve_err_t returned by the underlying call (also stored in last_error_). Uses FLUX_API.valves (must be initialised).
Note
Implemented by the SolenoidValve and ProportionalValve subclasses. Called by every writer (manifold control loop, mode threads, console commands, calibration / leak controllers, verified-stop helper). Mutex-protected at the HAL ValveManager so concurrent calls are safe.

Implements manifold_valves::Valve.

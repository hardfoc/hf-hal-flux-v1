Detailed Description

Reads raw ADC voltage and converts to engineering pressure units.

Thread-safe: AdcManager reads are mutex-protected internally, and the ADS7952 is on its own SPI bus so no contention with other SPI traffic.

Supports ratiometric sensors — voltage_min/max are computed from actual VA.

Line swap handling (calibration-time only via CalibrateSwap()):

  • For single-ended (DIR_POSITIVE/DIR_NEGATIVE): auto-detect using configured direction as ground truth, or override with expected_direction parameter
  • For differential (DIR_EITHER): REQUIRES expected_direction parameter to determine ground truth — otherwise can't auto-detect
  • If swap detected and auto_swap=true: swap applied automatically
  • If swap detected and auto_swap=false: reported but not applied

Calibration sequence:

  1. CalibrateVA() — determine actual supply voltage from atmospheric sensors
  2. CalibrateZero() — for each sensor, store atmospheric offset
  3. CalibrateSwap() — sample for a duration while valve opens, detect swap
  4. Sample() — normal operation (just applies swap flag, no detection)

noexcept

Calibrate swap by sampling during pressure application.

Samples for specified duration to track min/max pressure readings. Another thread should actuate valves to create measurable pressure change during this time. After sampling:

  • Determines which direction pressure predominantly went
  • Compares to ground truth (expected_direction or configured direction)
  • If opposite: swap is detected

For single-ended sensors (DIR_POSITIVE/DIR_NEGATIVE):

  • Ground truth = expected_direction if provided, else configured direction
  • Can auto-detect swap based on measured vs ground truth

For differential sensors (DIR_EITHER configured):

  • Ground truth = expected_direction (REQUIRED)
  • If not provided: cant_determine=true, no action taken
Parameters
duration_msHow long to sample for (during which valves may actuate)
sample_interval_msDelay between samples
expected_directionOverride ground truth direction (required for DIR_EITHER)
apply_if_detectedIf true and swap detected, apply it automatically
Returns
SwapCalibrationResult with details of what was detected/applied

◆ ConfigureFilter()

void PressureSensor::ConfigureFilter ( float cutoff_hz,
float sample_hz )
noexcept

Configure the per-channel single-pole IIR low-pass filter.

Coefficient is computed from cutoff and sample rate as alpha = 1 - exp(-2*pi*fc/fs) The first sample after (re)configuration primes the filter to that value (no transient). Pass cutoff_hz <= 0 or >= fs/2 to disable filtering.

Parameters
cutoff_hzCutoff frequency (Hz). Default 100 Hz.
sample_hzWorker thread sample rate (Hz). Default 1000 Hz.

◆ Update()

void PressureSensor::Update ( float voltage_raw)
noexcept

Feed an externally-acquired raw voltage sample to this channel.

Designed for the high-rate sampling worker that performs a single batched SPI transaction (Auto-1) per cycle and then dispatches each channel reading here. Performs:

  1. Single-pole IIR low-pass on the voltage stream (configurable cutoff).
  2. Voltage→pressure conversion via VoltageToPressureRaw() using the calibrated VA + zero-offset anchor.
  3. Atomic publish of the filtered voltage and pressure for lock-free consumption by control-loop threads at any rate.

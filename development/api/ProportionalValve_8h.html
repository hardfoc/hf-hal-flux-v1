Detailed Description

TLE92466ED-driven precision proportional valve.

@Browser Wraps a Flux::ValveManager proportional channel (TLE92466ED backend) with the per-model PWM frequency, slew rate, optional dither and full-flow current pulled from ManifoldValvesCatalog.h.

Position semantics: 0 → 0 mA / valve closed (NC family); 1 → full_flow_current_ma. The mapping is linear; control loops can perform any further linearisation in software.

On the very first apply the class pushes a complete tle92466ed::ChannelConfig (mode + open-load threshold + slew rate + dither) and enters mission mode through the handler; subsequent applies just update the current setpoint.

The diagnostics thread refreshes a per-channel Snapshot() that surfaces every fault flag, every warning, and the live measured current / duty-cycle / VBAT readings the chip publishes.

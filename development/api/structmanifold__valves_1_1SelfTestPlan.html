Detailed Description

Per-valve enable mask + tunable knobs for the boot self-test.

Defaults: every valve in the catalog is tested; the user can flip any enable_* flag to false in the application before calling ManifoldValvesSelfTest::Run.

◆ parallel_settle_ms

uint32_t manifold_valves::SelfTestPlan::parallel_settle_ms {500}

Settle wait per stress-test level (ms). 500 ms covers the slowest VSO solenoid family at full current under simultaneous load (which briefly droops VBAT and lengthens the chip's CDR settling time compared to a single-channel test). LM-Pro can still shortfall even at 500 ms when total simultaneous current crosses the bench PSU's regulation envelope — that's a real failure to be flagged by the tolerance band, not a settling artifact.

◆ prop_max_failed_steps

Maximum number of steps in the full ladder that may fail any of the {settled, accurate, low-noise} checks before the whole valve is marked FAIL. ≥ 1 absorbs the very-low-end noise pass that the chip can't reach (e.g. setpoint 0 mA reads back -2 mA).

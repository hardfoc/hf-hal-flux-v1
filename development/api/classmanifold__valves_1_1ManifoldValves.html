hf_valve_err_t manifold_valves::ManifoldValves::ConfigureGlobalDpm ( float start_current_ma,
float dip_threshold_ma,
float debounce_ms )
inlinenoexcept

Push the global MAX22200 Detection-of-Plunger-Movement (DPM) configuration. Per-channel DPM enable bits are pushed by each SolenoidValve::ApplyChannelFeatures() based on the catalog's Max22200ChannelFeatures::plunger_movement_detection flag.

Parameters
start_current_maISTART — current at which the dip search begins.
dip_threshold_maIPTH — minimum dip amplitude to count as movement.
debounce_msTDEB — minimum dip duration in milliseconds.

@Browser The driver converts the floating-point inputs into the DPM register encoding using IFS and the active chopping frequency. Tune the three parameters per the C15/C21 datasheets and the bench's mechanical signature.

Note
Safe to call multiple times. Returns the underlying driver error if anything goes wrong.

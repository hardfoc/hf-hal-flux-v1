Detailed Description

MAX22200-driven solenoid valve — supports both BinaryHitHold and VariableCurrent (pseudo-proportional) drive modes.

@Browser Wraps a Flux::ValveManager solenoid channel with the C15/C21 hit-and-hold profile (or, for SEV, the VSO-as-pseudo-proportional profile) pulled from ManifoldValvesCatalog.h.

Position semantics:

  • BinaryHitHold — pos > 0 → energise (hit then hold), pos == 0 → de-energise.
  • VariableCurrent — pos ∈ [0,1] → current ∈ [0, full_flow_current_ma] written into both hit and hold setpoints with hit_time = 0 so the channel runs at a steady current with no hit pulse.

Per-channel diagnostic features (open-load, plunger-movement, hit-current check, slew-rate control) are configured once via ApplyChannelFeatures() and surface through Snapshot().

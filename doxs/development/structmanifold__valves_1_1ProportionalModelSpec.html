Detailed Description

Datasheet-driven proportional model record (TLE92466ED).

The mapping position 0..1 → current uses these limits:

  • Position 0 → 0 mA (valve fully closed for NC types).
  • Position 1 → full_flow_current_ma.

dither_* are optional and only useful for VSO-class proportionals to reduce stiction; the LM-Pro is a linear-motor design and does not benefit from dither.

Detailed Description

Driver for the boot self-test.

Owns no state; everything lives on the stack of Run(). The class exists purely as a namespace for the helpers. Logs use the ManifValvesSelf ESP-IDF tag at INFO level for normal flow and WARN/ERROR for faults.

Run the configured self-test plan synchronously on the caller.

Caller MUST have brought up ManifoldValvesControlThread and ManifoldValvesDiagnosticsThread already (otherwise targets won't reach hardware and diagnostics won't be refreshed).

Parameters
systemShared ManifoldValves instance.
diagDiagnostics thread (used to pull subsystem-level health).
planTest plan (defaults to SelfTestPlan::All()).
Returns
Per-valve report. overall_pass is true if every enabled valve passed.
Reference to a static report. Held by the self-test instance; do not call Run() concurrently from multiple threads.

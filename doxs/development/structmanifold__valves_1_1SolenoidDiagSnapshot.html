Detailed Description

Per-channel MAX22200 diagnostic snapshot.

Surfaces every fault flag the driver IC publishes for a single channel — caller code can read each without inspecting raw bitmasks.

In medical devices these flags are the early-warning system:

  • overcurrent: short to supply, wrong load wired, ESD damage.
  • hit_not_reached: HIT current was not achieved within tHIT — coil resistance drifted, supply sagged, or the load is open.
  • open_load: no current path detected — disconnected coil or wire.
  • plunger_movement_fault: the plunger did NOT move under load — stuck mechanism, missing armature, or clogged seat. Critical mechanical-failure indicator.

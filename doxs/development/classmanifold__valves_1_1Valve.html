Detailed Description

Common state owned by every valve — base for SolenoidValve / ProportionalValve.

Thread safety
  • RequestState / RequestPosition / Get* methods are lock-free and safe to call from any thread at any rate.
  • Apply / OnDiagnostics are intended for the control / diagnostics threads only; the system class enforces single-writer ownership.
Atomic snapshot semantics
Three independent atomics are used:
  • target_pos_ — last setpoint requested by the app (0..1).
  • actual_pos_ — last position the control thread successfully applied (0..1). 0 ≡ closed, 1 ≡ fully open / energised.
  • state_ and last_error_ — most recent operational status. Releases on store / acquires on load give consumers a self-consistent snapshot (within the same valve) without locks.

virtual hf_valve_err_t manifold_valves::Valve::Apply ( )
pure virtualnoexcept

Apply the current setpoint to the underlying driver IC.

Returns
The hf_valve_err_t returned by the underlying call (also stored in last_error_). Uses FLUX_API.valves (must be initialised).
Note
Implemented by the SolenoidValve and ProportionalValve subclasses. Called by every writer (manifold control loop, mode threads, console commands, calibration / leak controllers, verified-stop helper). Mutex-protected at the HAL ValveManager so concurrent calls are safe.

Implemented in manifold_valves::ProportionalValve, and manifold_valves::SolenoidValve.

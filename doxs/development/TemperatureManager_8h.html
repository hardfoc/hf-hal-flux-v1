Detailed Description

Temperature sensor management for the HardFOC Flux V1 platform.

The Flux board temperature sources include:

  1. ESP32 internal temperature sensor (on-chip)
  2. NTC thermistor on the internal ADC
  3. MCP9700 on ADS7952 channel 8 (when the external ADC is present)

No TMC9660 temperature sensor (Flux has no motor controller).

Stack-friendly design: fixed-size array of TempEntry structs, no heap vectors or unordered_maps. Sensor driver instances are individually heap-allocated via unique_ptr (singleton lifetime).

Temperature manager error codes for consistent error reporting.

Manager-layer errors that are sensor-family agnostic. Driver-level errors (hf_temp_err_t) are translated into this common manager error domain.

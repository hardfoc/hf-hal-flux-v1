Detailed Description

Compile-time catalog of all WH bench valves and their datasheet specs.

Single source of truth for the bench valve set:

  • Two named ID enums (one per valve family) that drive O(1) lookup.
  • A model database for the Parker valves we drive (C21/C15 cartridge solenoids, VSO/VSO LowPro/LM-Pro proportionals) with the electrical numbers pulled directly from each datasheet. Adding/removing a model is a single literal change here; nothing else in the system changes.
  • Two compile-time mapping tables (kSolenoidMap, kProportionalMap) assigning each named valve to a Flux::ValveChannel and a model.
  • Per-valve diagnostic feature gates (open-load, plunger-movement, hit- current check, slew-rate control) — opt in only what the underlying load actually supports so we don't get spurious faults.
Driver IC mapping (Flux V1 board)
  • MAX22200 (8 channels) drives every solenoid:
    • BinaryHitHold mode — classic on/off cartridge solenoids (C21 / C15) using a calibrated hit pulse + reduced hold current (datasheet "Optional Reduced Power Control Method").
    • VariableCurrent mode — for proportional valves that are being controlled with the MAX22200's 7-bit CDR ladder for coarse 0–127 step current control. The driver writes the same setpoint to both hit and hold fields with hit_time = 0, producing a sustained constant current proportional to the requested position.
  • TLE92466ED (6 channels) drives the precision proportionals (FCV/FRV/LSV/GFV/SPV_H/SPV_L) with full current control + PWM + dither + per-channel current/duty/temperature feedback.
Acquisition references
  • Honeywell SSC TruStability — sensor side (see PressureSensorConfig.h).
  • Parker C21 cartridge solenoid (Hit-and-Hold §"Optional Reduced Power Control Method", 2.5 W full hit, 50 % hold, ≥ 1 kHz PWM).
  • Parker C15 cartridge solenoid (Hit-and-Hold §"Optional Reduced Power Control Method", 1.1–1.7 W full hit, 50 % hold, ≥ 1 kHz PWM).
  • Parker VSO TruStability proportional (Table 2, current-controlled, 5–12 kHz PWM).
  • Parker LM-Pro linear-motor proportional (Table 1, current-controlled, 5 kHz PWM minimum).

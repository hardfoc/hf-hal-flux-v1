Detailed Description

Manages multi-sensor VA calibration.

Uses sensors marked with use_for_va_cal=true to determine actual VA. Also performs per-sensor zero offset calibration.

Perform swap calibration on all sensors.

For each sensor, calls CalibrateSwap() with the specified duration. This method is blocking — another task should actuate valves during this time to create measurable pressure changes.

float PressureSensorCalibrator::CalibrateVA ( )

Perform VA calibration using atmospheric sensors.

Reads all sensors marked with use_for_va_cal=true, verifies they agree within tolerance, and calculates VA = 2 × average_voltage.

Returns
Calibrated VA voltage, or 0.0f if calibration failed

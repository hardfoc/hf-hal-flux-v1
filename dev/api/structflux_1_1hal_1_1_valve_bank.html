HalResult flux::hal::ValveBank::EnablePins ( bool  on)
staticnoexcept

Drop (false) or re-arm (true) both valve-bank enable pins.

Parameters
onfalse: drive both enables low now, latch the drop, refuse channel energising calls. true: re-arm by re-running the valve bring-up, which raises both pins.
Returns
Ok, or Err(HardwareFault) when a pin could not be driven / bring-up failed, Err(NotInitialized) when no enable pin exists (GPIO manager down) on a drop.

Detailed Description

Singleton that manages all ESP32 GPIO pins defined in the X-MACRO pin config.

Registers GPIO and USER category pins, provides name-based and enum-based access to the underlying BaseGpio drivers, and offers high-level Set/Read/Toggle/Interrupt operations routed by pin name. Thread-safe via RtosMutex.

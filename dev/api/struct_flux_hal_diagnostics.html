Detailed Description

Board-level bring-up snapshot: every manager's state and every fitted part's readiness.

Filled by Flux::CollectDiagnostics. Managers fail closed, so a part that did not come up shows here as not ready and its manager as not initialised with a reason; the part flags are valid even when their manager failed (they say which part is missing).

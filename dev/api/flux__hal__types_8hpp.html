Detailed Description

Shared HAL types for Flux V1: the manager error catalog and the facade result.

Purpose

Two error lanes, as in pw-hal's coding standards (coding-standards-managers.md §2): managers return bool and stash a flux::hal::ManagerError (read with GetManagerError()); facades return a flux::hal::HalResult. Do not add a third per-manager error enum when flux::hal::ManagerError fits.

The older per-manager operation enums (hf_valve_err_t, CommError, TemperatureError, LedError, ...) stay on the existing operation APIs and their GetLastError(); they are migrated when a manager is next reworked, not in one sweep.

Ownership

Types only. No MCU or RTOS header.

Thread safety: value types; no shared state.

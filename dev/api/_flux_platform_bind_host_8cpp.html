Detailed Description

Host implementation of the Flux platform binding over the hf-core host fakes.

Same slot layout as the ESP32-S3 binding (bsp_bind/esp32s3/), so a manager under test runs exactly the code it runs on the board; only the objects behind the Base* pointers differ. Scripting and inspection: FluxHostBind.h.

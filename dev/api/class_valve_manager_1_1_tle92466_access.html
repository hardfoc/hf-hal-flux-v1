Detailed Description

Locked access to the TLE92466ED for features this manager does not wrap.

Every call takes the handler's mutex: the TLE92466ED answers a read on the next chip select, so interleaved accesses from two threads consume each other's replies. No raw driver pointer: driver calls run inside WithDriver(), under that mutex. An empty access (bank not up) refuses every call with DriverError::NotInitialized.

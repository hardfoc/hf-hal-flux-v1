enum class flux::hal::ManagerError : uint16_t
strong

Lifecycle / bind failure catalog shared by every manager (GetManagerError()).

Set by a manager when EnsureInitialized() fails (fail-closed: the manager then reports IsInitialized() == false) or when a later operation finds the hardware gone. None after a successful EnsureInitialized().

Enumerator
None 

No error recorded.

NotInitialized

Detailed Description

Flux V1 board wiring that is not in the pin map: bus controllers, clocks, modes, bit rates.

The functional pin map (hf-pincfg hf_functional_pin_config_flux_v1.hpp) says which GPIO carries which signal. This header holds the rest of the board's bus facts, as plain constants with no MCU header: which SPI controller each bus uses, the clock and mode of each chip select, the CAN bit rate and the status LED. CommChannelsManager and LedManager turn them into flux::bsp specs. A board revision changes this file and the pin map, not the managers.

Ownership: constants only. Thread safety: constexpr; no state.

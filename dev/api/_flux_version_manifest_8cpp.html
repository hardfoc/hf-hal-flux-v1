Detailed Description

Static manifest of every component the Flux HAL links against.

Driver semvers are picked up via __has_include so this compiles cleanly even when a driver's generated header is not on the include path (in which case the version column reads "n/a"). Git SHAs come from the configure-time flux_hal_git_manifest.h.

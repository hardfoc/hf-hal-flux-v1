Detailed Description

ESP32-S3 implementation of the Flux platform binding (bsp_bind/FluxPlatformBind.h).

The only translation unit of the HAL that names Esp* wrappers, ESP-IDF headers or the WS2812 RMT driver. Every object lives in a fixed std::optional slot in static storage, so the binding itself never calls the heap allocator; the ESP-IDF drivers underneath (SPI master, TWAI, UART, RMT) allocate their own queues inside the Create* call, which runs from the owning manager's EnsureInitialized().

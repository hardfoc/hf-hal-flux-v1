Detailed Description

Locked access to the MAX22200 for features this manager does not wrap.

Every call takes the handler's mutex, so it cannot interleave with the manager's own accesses or another thread's (the MAX22200's two-phase CMD-pin protocol breaks when a peer transaction lands between the phases). There is no raw driver pointer: driver calls the handler does not wrap run inside WithDriver(), under that mutex. An empty access (bank not up) refuses every call.

Detailed Description

Singleton manager for all temperature sensors on Flux V1.

Manages the ESP32 internal temperature sensor and the NTC thermistor connected via ADC (GPIO4 / ADC1_CH4). Sensors are registered in a fixed-size array at initialisation; readings are returned in Celsius or Fahrenheit.

Note
Call EnsureInitialized() once before any reads. All public methods are thread-safe (guarded by an internal RTOS mutex).

Detailed Description

Unified singleton entry point for the HardFOC Flux V1 platform.

Orchestrates initialisation of all subsystem managers (NVS, Comms, GPIO, Valves, ADC, LED, Temperature) in deterministic order and exposes them as public reference members for direct access. Provides system-level diagnostics, health checking, graceful shutdown, and runtime warning collection.

uint32_t Flux::GetLastResetReason ( ) const
noexcept

Reset reason of the previous boot, opaque to callers.

Wraps esp_reset_reason() on ESP32 today; on other MCUs an equivalent vendor enum will back this. Apps treat the return as an opaque uint32_t they can persist to NVS or print verbatim; decoding is platform-specific and lives in HAL utilities.

Returns

◆ SystemRestart()

void Flux::SystemRestart ( ) const
noexcept

Trigger a software reset of the MCU. Does not return on success.

Wraps esp_restart() on ESP32. Apps call this from supervisor paths (e.g. app_main's recovery loop) when something has gone unrecoverably wrong. The HAL closes/flushes nothing here — the caller is responsible for any pre-reboot logging or NVS commit.

Detailed Description

Unified singleton for controlling all valve channels on the Flux board.

Provides a single API surface for both solenoid (MAX22200) and proportional (TLE92466ED) valve channels. The manager owns both handler instances and resolves channel requests to the correct backend automatically.

◆ DropEnablePins()

bool ValveManager::DropEnablePins ( )
noexcept

Drive MAX22200 ENABLE and TLE92466ED EN low: both banks de-energised in hardware.

The hardware half of SafeHold (architecture-port design §3.4, §3.8). Writes the two enable GPIOs directly: no SPI transfer, no mutex, no allocation, no logging, so it is safe from the safety thread at any priority while another thread is mid-transfer on the valve bus. It works whether or not the manager is initialised (the pins exist as soon as GpioManager is up).

After a drop the manager refuses every channel-energising call (EnableChannel, EnableChannelsMask) with VALVE_ERR_WRONG_MODE, so software never believes a valve is on while its bank is gated off. De-energising calls still work. The drop holds until RearmEnablePins.

This does not decide when to drop the pins or whether to vent first: that is the caller's policy (the product's safety arbiter; vent-then-hold is owner question Q2).

Note
Callable from task context of any priority. From an ISR only if the binding's GPIO write is ISR-safe; on the ESP32-S3 prefer waking the safety thread (gpio_set_level is not in IRAM).
Returns
true when every enable pin that exists was driven low.

◆ RearmEnablePins()

bool ValveManager::RearmEnablePins ( )
noexcept

Leave SafeHold: full re-bring-up of both banks, which raises the enable pins again.

The MAX22200 is not guaranteed to keep its configuration across an ENABLE low period, so re-arming is Deinitialize() followed by EnsureInitialized(): every channel off, handlers rebuilt, chips re-initialised, pins raised by their drivers. Takes the manager mutex and uses SPI; never call it from the safety path.

Returns
true when the manager is initialised again with both pins high.

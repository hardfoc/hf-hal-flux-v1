Detailed Description

Unified valve management system for the HardFOC Flux V1 platform.

Manages all valve outputs on the Flux board through two driver ICs:

  1. MAX22200 — 8-channel octal solenoid/motor driver
    • On/off solenoid control with CDR (current drive regulation)
    • HIT/HOLD current profiles for fast actuation
    • Best for: standard on/off solenoid valves
  2. TLE92466ED — 6-channel low-side driver with current regulation
    • Proportional current control per channel
    • PWM-based control for proportional valves
    • Best for: proportional solenoid valves, PWM-controlled actuators

The ValveManager provides a unified, type-safe API to configure and control all 14 valve channels through a single interface. Each channel is identified by a compile-time enum and its driver type is resolved at registration.

Design principles:

  • All channel descriptors live in fixed-size arrays.
  • Both handlers are members (std::optional, constructed in place during EnsureInitialized()): no heap allocation, before or after init.
  • Fail-closed bring-up: EnsureInitialized() succeeds only when every fitted driver IC came up. Otherwise the manager stays uninitialised, every channel operation is refused, and GetManagerError() says why. A bank that did come up stays reachable through its handler accessor, for diagnosis only.
  • O(1) index-based channel lookup; string lookups scan a small constexpr table.
  • Thread-safe via RtosMutex on state-changing operations.

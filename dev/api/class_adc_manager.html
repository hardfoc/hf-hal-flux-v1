Detailed Description

Singleton manager for all analogue-to-digital channels on Flux V1.

Provides a uniform API over the internal ESP32 ADC and optional external ADS7952 ADC(s). Channels are registered from the pincfg X-MACRO table at initialisation and can be looked up by name (linear scan) or by functional enum (O(1) index).

Note
Call EnsureInitialized() once before any reads. All public methods are thread-safe (guarded by an internal RTOS mutex).

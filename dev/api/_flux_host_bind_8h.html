Detailed Description

Host (unit-test) family of the Flux platform binding: scripting and inspection hooks.

FluxPlatformBindHost.cpp implements bsp_bind/FluxPlatformBind.h with the hf-core host fakes (hf_core_host_mocks): every GPIO is a MockGpio, every SPI chip select a MockSpi, the MCU ADC a MockAdc, NVS regions MockNvs, and so on, all in static slots exactly like the ESP32-S3 binding. This header lets a test reach those fakes, script them before a manager initialises, and inject failures. Only tests/host includes it.

Thread safety: none; host tests are single-threaded.

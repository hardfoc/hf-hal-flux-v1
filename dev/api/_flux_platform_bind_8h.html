Detailed Description

The MCU-family seam of the Flux V1 HAL: what a binding must provide to the managers.

The managers above this header are MCU-free: they decide what to bring up (which pins, which buses, which namespaces, in which order, and what a failure means) and talk to the result through hf-core Base* interfaces. This header names the small set of factory and system functions that turn a plain-data spec into a Base* object. Each MCU family implements every function once, in its own directory:

Directory Built when Backs the objects with
bsp_bind/esp32s3/ ESP-IDF build (HF_CORE_MCU=ESP32) Esp* wrappers, ESP-IDF, RMT driver
bsp_bind/host/ host test build hf-core host mocks

Exactly one family is linked into an image. ESP-IDF, FreeRTOS and Esp* headers may appear only under bsp_bind/<family>/ (enforced by tools/lint/lint_hal_boundary.sh).

Ownership: every object returned here lives in fixed static storage inside the binding (one slot per pin, bus, port or region). Nothing is heap-allocated by the binding itself; ESP-IDF drivers that allocate internally do so inside the Create* call, i.e. during the owning manager's EnsureInitialized().

Callers: managers only (the *Manager.cpp files in lib/managers) and the Flux facade for the system calls. Applications never include this header.

Thread safety: none inside the binding. Each slot has exactly one owning manager, which serialises its own calls (manager mutex or init-time only).

Error handling: Create* returns nullptr / false on failure and leaves the slot empty; the calling manager records the error. Destroy* on an empty slot is a no-op.

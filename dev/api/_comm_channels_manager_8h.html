Detailed Description

Communication channels manager for the HardFOC Flux V1 platform.

Manages board communication buses (SPI, CAN, lazy UART) for the Flux valve-control board. SPI talks to:

  • MAX22200 octal solenoid driver
  • TLE92466ED six-channel low-side driver CAN is used for external devices (e.g. compressor). There is no I²C bus on Flux V1 — GetI2cBus() always returns nullptr.

The bus objects are created by the platform binding (bsp_bind/FluxPlatformBind.h) in its static storage; this manager decides which buses and chip selects exist (pin map + board config) and holds Base* pointers only, so this header is MCU-free.
